{{/* Takes rendered record HTML, returns it with relative records/ links pointed at the forge's raw URL — the shape params.repoLinkStyle / repoBranch pick, resolved by repo-link.html. Shared by record.html and rss.xml so the feed and the page agree on where a link goes. The pattern matches a relative path only: records/x.md, ./records/x.md, ../../records/x.md — never one starting with / or with a scheme. Fuglekasse's inline copy is looser (href="[^"]*records/…), which also catches a site served under a path containing records/ — this project's own deployment — and would send every attachment URL the render hooks resolve (/records//file.pdf) off to the forge. */}} {{ $c := . }} {{ if site.Params.repoURL }} {{ $c = replaceRE `href="(?:\.\.?/)*records/([^"]+)"` (printf `href="%s/records/$1"` (partial "repo-link.html" (dict "kind" "raw"))) $c }} {{ end }} {{ return $c }}
